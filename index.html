Renewable Energy Project Lifecycle Management System

A Java application that tracks solar, wind and hydro projects from planning to maintenance, with role-based access and stage-gate rules that stop a project from skipping a stage.

The problem

Project teams track surveys, permits, equipment and maintenance in separate spreadsheets and emails.

Missed milestones

Nobody can see the true status of a project at a glance.

Duplicate records

The same equipment or task is entered in several places.

Our answer

One role-based Java system where every stage, task and equipment item is an object, and invalid moves are rejected.

Try the stage-gate engine

This is a JavaScript port of the Java advanceStage() logic. Pick a role, then try to break the rules.

Object-oriented design

Inheritance, abstraction, polymorphism and interfaces carry the design.

User (abstract)

ProjectManager, SiteEngineer and Admin each answer canPerform(action) in their own way, so no long if-chains.

Project (abstract)

SolarProject, WindProject and HydroProject extend it and each implement calcOutput().

Interfaces

Notifiable and Reportable give unrelated classes a shared ability.

Custom exceptions

InvalidStageTransition, MissingApproval and DuplicateProject explain exactly what went wrong.

Lifecycle rules

Six stages: Planning → Approval → Installation → Commissioning → Operation → Maintenance. A project moves ahead only when the current stage is Completed and approved by a Project Manager. No stage may be skipped or repeated.
