# Renewable Energy Project Lifecycle Management System

Java OOP project (CCSE0355), Group 45, B.Tech CSE-DS, NIET Greater Noida.

A role-based system for tracking solar, wind and hydro projects through six lifecycle stages with stage-gate rules, custom exceptions, JDBC transactions, an audit log and reports.

## Run the Java code

```
javac src/App.java
java -cp src App
```

## Project website

`index.html` is a static site with an interactive demo of the stage-gate engine. To publish it with GitHub Pages: repository **Settings > Pages > Deploy from a branch > main / (root)**.
